## 簡介

本專案是公車迷出於興趣製作的複刻程式，播報邏輯參考實體公車報站器，主要用於娛樂與學習；但同樣完全可以用於真實營運場景。

蘇北公車報站會依照車輛即時位置自動播放到站語音。它結合路線資料（`bus/*.csv`）、播報規則（`system/audiolist.csv`）與手機 GPS：車輛進入某站的「站前里程」範圍時自動播進站，離站後自動播出站；臨時改道時也能自動跳過沒經過的站點。

應用程式內建路線資料編輯器、audiolist 規則覆寫、限速覆寫、進出站靈敏度調整、響度均衡、聲道分離、8 套 Material 3 配色，以及完整的資料匯入／匯出，全部都能直接在手機上完成，不需要電腦。

資料包格式與「巴視通」「南大蘇富特」「江寧公交信息科技」等廠家的車載報站器 **100% 完美相容**，詳見[與主流車載報站器資料格式相容](#與主流車載報站器資料格式相容)。

- **套件名稱**：`org.rayista.subobus`
- **版本**：3.11（versionCode 32）
- **最低系統**：Android 8.0（API 26），目標 API 34
- **技術堆疊**：Kotlin + Jetpack Compose + Material 3

## 功能說明

### 1. 主畫面

- 頂部顯示 **GPS 狀態**與日期時鐘。
- **路線列**顯示目前路線、起點 → 終點，以及一鍵切換上行／下行。
- **目前站／下一站卡片**：站名、手機即時經緯度（十進制度），以及到下一站的剩餘距離。
- **操作按鈕**：報站、終止、重複、設定。
- **數字鍵盤 1–9、0**，`0` 兩側是 ▲／▼，用於切換站點但不播報。
- 底部**速度列**顯示目前車速與目前生效的限速。
- **橫式與直式分別排版**，所有控制項都在同一畫面內，不需要捲動。
- 主畫面所有按鍵支援**震動回饋**（可關閉）。
- 應用程式在前景時**保持螢幕恆亮**（可關閉）。
- **背景執行**：應用程式以前景服務執行，通知列常駐一則帶「報站／停止」按鈕的通知，功能與介面按鈕相同；退到背景（甚至關掉介面）仍會繼續 GPS 定位與自動進出站播報。

### 2. 自動進出站

- **進站**：GPS 到某站的距離進入該站「站前里程」範圍時觸發進站播報；該值為 0 時以 50 公尺作為預設值。
- **支援跳站**：進站判定會掃描所有站點，因此從第二站直接改道到第四站時，第三站會被跳過，直接播第四站。
- **出站**：車輛先進入站點 5 公尺的「重合」範圍，再離開到 50 公尺時觸發出站播報，且只觸發一次。
- **不會重複播報**：同一站點的進站、出站各只播一次，直到切換路線、方向或重新匯入資料後重置。
- **定位品質保護**：座標為 `0,0` 或精度差於 100 公尺時不參與判定。
- 切換路線、切換上下行、匯入資料都會重置自動判定狀態。

### 3. 播報內容與順序

- 播報步驟由 `system/audiolist.csv` 產生；找不到的 MP3 會靜默跳過，不會中斷整段播報。
- 進站是合併步驟：**先播進站播報，再播進站外音**。
- 起點站使用「起點播報」，終點站使用「終點播報」，終點前一站使用「終點預報」。
- 數字鍵會播放對應的 `服务音0.mp3` … `服务音9.mp3`（檔案存在時）。

### 4. 設定

設定項目依下列分組排列，修改後立即生效，重新啟動後仍會保留。

**主題配色**
- 8 套 Material 3 配色：4 套亮色（天空藍、青碧、暖陽、紫羅蘭）、3 套暗色（夜空藍、深林綠、暖棕）、1 套純黑（OLED）。
- 全部使用 Material 3 色彩角色取色，主畫面與設定頁會一起切換。

**通用**
- 前景保持螢幕恆亮。
- 按鍵震動回饋。
- **響度均衡**：把音量偏小的錄音自動提升到目標響度，原本就大聲的不處理。最大提升 15 dB，分析結果會依檔案快取。
- **介面語言**：可在簡體中文、繁體中文、English 之間切換；只切換介面文字，CSV、站名、音訊檔名等資料不變。首次啟動會自動跟隨系統語言（繁體系統用繁體中文、其它中文系統用簡體中文、其餘用英文），之後以手動選擇為準。
- **開啟背景執行**：開啟時顯示常駐通知（含「報站／停止」快捷按鈕），並保持背景定位與自動報站；關閉後通知消失，退到背景也不再保活（前景使用不受影響）。

**報站功能設定**
- **限速覆寫**：開啟後所有站點統一使用手動限速（1–999 km/h）；關閉時依路線 CSV 的站點限速。
- **是否播報超速提醒**：勾選時正常播放超速語音，取消則靜音。
- **超速提醒播放次數／間隔時間**：觸發一次超速後，**連續播放設定次數**（預設 2 次，次數之間不留間隔）；若仍持續超速，**間隔設定秒數**（預設 5 秒）後再播一輪。次數 1–20、間隔 1–999 秒，關閉超速提醒時兩項隱藏。
- **進出站靈敏度覆寫**：開啟後可分別設定進站、重合、出站靈敏度（1–999 公尺）；關閉時進站依 CSV 的站前里程，重合／出站使用預設 5 公尺／50 公尺。
- **覆寫 audiolist.csv**：開啟後用 7 個勾選框控制各類播報是否播放——起點播報、終點播報、終點預報、進站播報、出站播報、進站外音、出站外音。

**實驗性**
- **是否分離聲道**：依 audiolist 的內放／外放類型路由輸出——**進站外音、出站外音只走左聲道**；**起點播報、終點播報、終點預報、進站播報、出站播報只走右聲道**。單聲道檔案也能只從指定的一側出聲（應用程式會把單聲道複製成立體聲，再把另一側歸零）。
- **雙擊覆寫站點位置**：勾選後，在主畫面雙擊「目前站」卡片，會把手機目前經緯度寫回路線 CSV 的該站，並顯示「站點位置覆寫成功」提示。

**選擇路線**
- 可輸入搜尋的下拉選擇：輸入路線名稱的一部分即可篩選，也可直接從清單點選。

**資料匯入與匯出**
- 支援一鍵匯入整合 ZIP、匯入路線 ZIP、匯入音訊 ZIP、匯入單一 `audiolist.csv`。
- **分享匯入**：部分車機的檔案管理器不支援系統檔案選擇器（例如部分比亞迪車機），可在檔案管理器長按檔案 →「分享」→ 在分享面板選擇「一鍵匯入／匯入路線 ZIP／匯入音訊 ZIP／匯入 audiolist.csv」，四個入口分別對應上述四種匯入。分享進來的檔案會先複製到應用快取再匯入，不受 URI 授權過期影響。
- **一鍵匯出所有資料**：把 `bus/`、`mp3/`、`system/` 打包成一個 ZIP，可自選儲存目錄與檔名；匯出的壓縮檔可直接用「一鍵匯入」還原。

### 5. 路線資料編輯器

入口：**設定 → 選擇路線 → 新增路線／編輯路線**。

- **新增路線**會先要求輸入路線名稱；**編輯路線**直接開啟目前選取的路線，預設編輯上行。
- **頂部工具列**：返回、儲存、`＋`（在尾端新增空白站）、目前方向（上行／下行）、`⋮` 選單。
- **`⋮` 選單**：路線名稱（重新命名）、上下行切換、複製上行站點至下行。
- **站點清單**：一行一站，類似郵件清單，包含圓角序號徽章、站名、副標題（報站語音 · 站點類型 · 限速）、分隔線與拖曳把手。
- **左滑刪除**（紅色背景，不需要二次確認）；**右滑在上方插入**新站（高亮提示）。
- **長按整列或按住右側把手拖曳排序**：被拖曳的列會抬起並加上陰影，其他列平滑讓位，靠近頂部／底部會自動捲動；第一站與最後一站有阻尼，不會飛走。
- **站點編輯框**欄位：報站語音、站名、經度、緯度、角度、進站廣告、出站廣告、進站提示、出站提示、進站擴充、出站擴充、限速、站前里程、是否大站、外音開否。只有**報站語音與站名必填**；限速預設 50，站前里程預設 85。
- **是否大站**為單選：起點站／大站／小站／終點站（預設小站）。儲存時第一個站會自動改為起點站，最後一個自動改為終點站。
- **儲存**會重寫 CSV：站台編號依目前順序重新產生，上行／下行分別寫入。
- 有未儲存修改時按返回會跳出確認框；**取消**是實心主按鈕，避免誤點而遺失修改。
- 儲存後設定頁的路線清單會自動重新整理並切換到該路線。

## 資料格式

```
filesDir/
├── bus/
│   ├── 1/
│   │   ├── 1S.csv          # 上行
│   │   └── 1X.csv          # 下行
│   └── 通勤1号/
│       └── 通勤1号S.csv
├── mp3/
│   ├── 科技新城东园.mp3
│   └── 服务音1.mp3
└── system/
    └── audiolist.csv
```

路線檔名必須以 `S`（上行）或 `X`（下行）結尾、副檔名為 `.csv`。路線名稱可以包含非數字字元；顯示時只有結尾是數字才會自動加上「路」（`11 → 11 路`，`通勤1号 → 通勤1号`）。

### 路線 CSV 欄位

| 序號 | 欄名 | 說明 |
|---|---|---|
| 0 | 站台编号 | 站點序號，儲存時由編輯器重新產生 |
| 1 | 报站语音 | 音訊檔名（不含 `.mp3`） |
| 2 | 站名 | 顯示名稱 |
| 3 | 经度 | **度分格式**（DDMM.MMMM） |
| 4 | 纬度 | **度分格式**（DDMM.MMMM） |
| 5 | 角度 | 方向角 |
| 6 | 进站广告 | 進站廣告音訊 |
| 7 | 出站广告 | 出站廣告音訊 |
| 8 | 进站提示 | 進站提示音訊 |
| 9 | 出站提示 | 出站提示音訊 |
| 10 | 进站扩展 | 進站擴充音訊 |
| 11 | 出站扩展 | 出站擴充音訊 |
| 12 | 限速 | 限速（km/h） |
| 13 | 站前里程 | 進站觸發距離（公尺） |
| 14 | 是否大站 | `起点站`／`大站`／`小站`／`终点站` |
| 15 | 外音开否 | `是`／`否` |

> 經緯度使用「度 + 十進位分」格式：`11930.6582` 代表 119°30.6582′，換算成十進制度是 119.51097°。應用程式比對 GPS 時會自動轉換。

### audiolist.csv

前兩欄是 `播报类型` 與 `是否播报`（`是`／`否`），後面是該播報類型對應的音訊欄位。支援的類型：`起点播报`、`终点播报`、`终点预报`、`进站播报`、`出站播报`、`进站外音`、`出站外音`。

### 與主流車載報站器資料格式相容

本專案的路線資料包（`bus/` + `mp3/` + `system/`）沿用主流車載報站器通用格式，**可與「巴視通」「南大蘇富特」「江寧公交信息科技」等廠家的車載報站器資料達到 100% 完美相容**，雙向匯入匯出都不需要手動轉換：

- **目錄結構一致**：`bus/[路線名]/[路線名]S.csv`、`[路線名]X.csv`、`mp3/`、`system/audiolist.csv`
- **路線 CSV 欄位順序與意義一致**：固定 16 欄（站台編號 → 外音開否），經緯度同為「度分」格式（DDMM.MMMM）
- **播報規則一致**：`audiolist.csv` 的播報類型與音訊欄位對應（起點播報、終點播報、終點預報、進站播報、出站播報、進站外音、出站外音）
- **檔名規則一致**：`S` = 上行、`X` = 下行，副檔名與字母大小寫不敏感（`11s.csv`、`11S.CSV` 均可辨識並統一規範為大寫）
- **編碼自動相容**：UTF-8、UTF-8 BOM、UTF-16（LE/BE）、GB18030/GBK 均可直接匯入，入庫統一轉為 UTF-8；匯出的 CSV 為 UTF-8，可被廠商軟體再次匯入，中文不亂碼
- **音訊依檔名比對**：路線 CSV 內填檔名（不含 `.mp3`），找不到的單一檔案會靜默略過，不影響同組其他播報
- **匯出可直接交付**：「一鍵匯出所有資料（ZIP）」依 `bus/`、`mp3/`、`system/` 原始結構打包，可直接交給廠商工具或複製到另一台車機

> 換句話說：把廠商報站器匯出的資料包直接「一鍵匯入」到本 App，或把本 App 匯出的 ZIP 交給廠商工具，皆無需重排欄位、轉編碼或改名。若某廠商使用非標準延伸欄位或特殊命名，回報資料包即可依同一格式調整。

## 首次啟動（不含內建資料）

本倉庫與安裝檔**不包含任何路線資料與音訊檔案**：開發測試用的路線與 mp3 已全部移除，以避免版權問題。首次啟動時路線清單為空，可以：

1. 進入 **設定 → 資料匯入／匯出**，匯入廠商的資料包（路線 ZIP、音訊 ZIP、`audiolist.csv`，或整合 ZIP 一鍵匯入）；或
2. 用 **設定 → 新增路線** 在內建編輯器建立路線，再把 mp3 放進 App 的 `mp3/` 目錄。

缺少 `system/audiolist.csv` 時會自動使用內建的預設播報規則，因此只匯入路線 CSV 與音訊也能正常運作。

若要在本機建置時帶上自己的測試資料，放到 `app/src/main/assets/bus`、`app/src/main/assets/mp3`、`app/src/main/assets/system` 即可——這三個路徑已寫入 `.gitignore`，不會被提交到倉庫。

## 建置與執行

需要 JDK 17、Android SDK 34，可使用 Android Studio 或命令列。

```bash
# 指定 SDK 位置（Windows 範例）
echo "sdk.dir=C:/Users/<你的使用者名稱>/android-sdk" > local.properties

# 建置 Debug APK
./gradlew assembleDebug

# 產物
app/build/outputs/apk/debug/app-debug.apk
```

首次啟動需要授予定位權限；沒有定位權限時自動報站無法使用，手動報站仍可正常操作。

## 說明與已知行為

- **響度均衡預設關閉**。開啟後每個檔案首次播放前會先分析（最多取樣 30 秒），因此第一次可能略有延遲，之後使用快取。
- **聲道分離在 PCM 層完成**，所以單聲道檔案也能只從指定的一側出聲；立體聲檔案會把對應一側的內容保留在選定聲道。
- **雙擊覆寫站點位置**修改的是應用程式內部的路線 CSV 副本；重新匯入路線包會覆蓋這些手動修正。
- 切換路線、方向或匯入資料後，自動播報狀態會重置，之前播過的站點可能會依新位置重新觸發。
- 匯出的 ZIP 會保持 `bus/`、`mp3/`、`system/` 目錄結構，可直接用「一鍵匯入」還原。
- 匯入時會自動偵測編碼並統一轉為 UTF-8，Windows／GBK 編碼的 CSV 也能正常處理。
