# Subo Bus Announcement 苏北公交报站

**面向公交车爱好者的 GPS 自动报站应用。**

[English](README.md) | 简体中文 | [繁體中文](README.zh-TW.md)

> 界面文字支持简体中文、繁體中文、English 三语，可在「报站器设置 → 通用 → 界面语言」随时切换；本文以简体中文撰写。

## 简介

本项目是公交迷出于兴趣做的复刻程序，播报逻辑参考实体公交车报站器，主要用于娱乐与学习；但同样可以用于真实运营场景。

苏北公交报站会根据车辆实时位置自动播报到站信息。它把线路数据（`bus/*.csv`）、播报规则（`system/audiolist.csv`）和手机 GPS 结合起来：车辆进入某站的「站前里程」范围时自动报进站，离站后自动报出站；临时绕行时还能自动跳过没经过的站点。

应用内置线路数据编辑器、audiolist 规则覆写、限速覆写、进出站灵敏度调节、响度均衡、声道分离、8 套 Material 3 配色，以及完整的数据导入/导出，全部可以直接在手机上完成，不需要电脑。

数据包格式与「巴视通」「南大苏富特」「江宁公交信息科技」等厂家的车载报站器 **100% 完美兼容**，详见[与主流车载报站器数据格式兼容](#与主流车载报站器数据格式兼容)。

- **包名**：`org.rayista.subobus`
- **版本**：3.7（versionCode 28）
- **最低系统**：Android 8.0（API 26），目标 API 34
- **技术栈**：Kotlin + Jetpack Compose + Material 3

## 功能说明

### 1. 主界面

- 顶部显示 **GPS 状态**和日期时钟。
- **线路栏**显示当前线路、起点 → 终点，以及一键切换上行/下行。
- **当前站 / 下一站卡片**：站名、手机实时经纬度（十进制度），以及到下一站的剩余距离。
- **操作按钮**：报站、终止、重复、设置。
- **数字键盘 1–9、0**，`0` 两侧是 ▲ / ▼，用于切换站点但不播报。
- 底部**速度栏**显示当前速度和当前生效的限速。
- **横屏与竖屏分别排版**，所有控件都在一屏内，不需要滚动。
- 主界面所有按键支持**震动反馈**（可关闭）。
- 应用在前台时**保持屏幕常亮**（可关闭）。

### 2. 自动进出站

- **进站**：GPS 到某站的距离进入该站「站前里程」范围时触发进站播报；该值为 0 时按 50 米兜底。
- **支持跳站**：进站判定会遍历所有站点，所以从第二站直接绕到第四站时，第三站会被跳过，直接播第四站。
- **出站**：车辆先进入站点 5 米「重合」范围，再离开到 50 米时触发出站播报，且只触发一次。
- **不会重复播报**：同一站点的进站、出站各只播一次，直到切换线路、方向或重新导入数据后重置。
- **定位质量保护**：坐标为 `0,0` 或精度差于 100 米时不参与判定。
- 切换线路、切换上下行、导入数据都会重置自动判定状态。

### 3. 播报内容与顺序

- 播报步骤由 `system/audiolist.csv` 生成；找不到的 MP3 会静默跳过，不中断整条播报。
- 进站是合并步骤：**先播进站播报，再播进站外音**。
- 起点站使用「起点播报」，终点站使用「终点播报」，终点前一站使用「终点预报」。
- 数字键会播放对应的 `服务音0.mp3` … `服务音9.mp3`（存在时）。

### 4. 设置

设置项按以下分组排列，修改后立即生效，重启应用仍保留。

**主题配色**
- 8 套 Material 3 配色：4 套亮色（天空蓝、青碧、暖阳、紫罗兰）、3 套暗色（夜空蓝、深林绿、暖棕）、1 套纯黑（OLED）。
- 全部使用 Material 3 颜色角色取色，主界面和设置页一起切换。

**通用**
- 前台保持屏幕常亮。
- 按键震动反馈。
- **响度均衡**：把音量偏小的录音自动提升到目标响度，音量本来就大的不处理。最大提升 15 dB，分析结果按文件缓存。
- **界面语言**：可在简体中文、繁體中文、English 之间切换；只切换界面文字，CSV、站名、音频文件名等数据不变。

**报站功能设置**
- **限速覆写**：开启后所有站点统一使用手动限速（1–999 km/h）；关闭时按线路 CSV 的站点限速。
- **是否播报超速提醒**：勾选正常播报超速语音，取消则静音。
- **进出站灵敏度覆写**：开启后可分别设置进站、重合、出站灵敏度（1–999 米）；关闭时进站按 CSV 的站前里程，重合/出站使用默认 5 米 / 50 米。
- **覆写 audiolist.csv**：开启后用 7 个勾选框控制每类播报是否播放——起点播报、终点播报、终点预报、进站播报、出站播报、进站外音、出站外音。

**实验性**
- **是否分离声道**：按 audiolist 的内放/外放类型路由输出——**进站外音、出站外音只走左声道**；**起点播报、终点播报、终点预报、进站播报、出站播报只走右声道**。单声道文件也能正常只从指定一侧出声（应用会把单声道复制成立体声，再把另一侧置零）。
- **双击覆写站点位置**：勾选后，在主界面双击「当前站」卡片，会把手机当前经纬度写回该站的线路 CSV，并弹出「站点位置覆写成功」。

**选择线路**
- 可输入搜索的下拉选择：输入线路名的一部分即可过滤，也可以直接点列表选择。

**数据导入和导出**
- 支持一键导入整合 ZIP、导入线路 ZIP、导入音频 ZIP、导入单个 `audiolist.csv`。
- **一键导出所有数据**：把 `bus/`、`mp3/`、`system/` 打包成一个 ZIP，可自选保存目录和文件名；导出的包可直接用「一键导入」还原。

### 5. 线路数据编辑器

入口：**设置 → 选择线路 → 新增线路 / 编辑线路**。

- **新增线路**会先要求输入线路名称；**编辑线路**直接打开当前选中的线路，默认编辑上行。
- **顶部工具栏**：返回、保存、`＋`（在末尾新增空白站）、当前方向（上行/下行）、`⋮` 菜单。
- **`⋮` 菜单**：线路名称（重命名）、上下行切换、复制上行站点至下行。
- **站点列表**：一行一个站，类似邮件列表，包含圆角序号徽章、站名、副标题（报站语音 · 站点类型 · 限速）、分割线和拖拽手柄。
- **左滑删除**（红色背景，不需要二次确认）；**右滑在上方插入**新站（高亮提示）。
- **长按整行或按住右侧手柄拖动排序**：被拖行会抬起加阴影，其他行平滑让位，靠近顶部/底部会自动滚动；第一站和最后一站有阻尼，不会飞走。
- **站点编辑框**字段：报站语音、站名、经度、纬度、角度、进站广告、出站广告、进站提示、出站提示、进站扩展、出站扩展、限速、站前里程、是否大站、外音开否。只有**报站语音和站名必填**；限速默认 50，站前里程默认 85。
- **是否大站**为单选：起点站 / 大站 / 小站 / 终点站（默认小站）。保存时第一个站自动改为起点站，最后一个自动改为终点站。
- **保存**会重写 CSV：站台编号按当前顺序重新生成，上行/下行分别写入。
- 有未保存修改时点返回会弹确认框；**取消**是实心主按钮，避免误点丢失修改。
- 保存后设置页的线路列表会自动刷新并切换到该线路。

## 数据格式

```
filesDir/
├── bus/
│   ├── 1/
│   │   ├── 1S.csv          # 上行
│   │   └── 1X.csv          # 下行
│   └── 通勤1号/
│       └── 通勤1号S.csv
├── mp3/
│   ├── 科技新城东园.mp3
│   └── 服务音1.mp3
└── system/
    └── audiolist.csv
```

线路文件名必须以 `S`（上行）或 `X`（下行）结尾、扩展名为 `.csv`。线路名可以包含非数字字符；显示时只有结尾是数字才自动加「路」（`11 → 11 路`，`通勤1号 → 通勤1号`）。

### 线路 CSV 列

| 序号 | 列名 | 说明 |
|---|---|---|
| 0 | 站台编号 | 站点序号，保存时由编辑器重新生成 |
| 1 | 报站语音 | 音频文件名（不含 `.mp3`） |
| 2 | 站名 | 显示名称 |
| 3 | 经度 | **度分格式**（DDMM.MMMM） |
| 4 | 纬度 | **度分格式**（DDMM.MMMM） |
| 5 | 角度 | 方向角 |
| 6 | 进站广告 | 进站广告音频 |
| 7 | 出站广告 | 出站广告音频 |
| 8 | 进站提示 | 进站提示音频 |
| 9 | 出站提示 | 出站提示音频 |
| 10 | 进站扩展 | 进站扩展音频 |
| 11 | 出站扩展 | 出站扩展音频 |
| 12 | 限速 | 限速（km/h） |
| 13 | 站前里程 | 进站触发距离（米） |
| 14 | 是否大站 | `起点站` / `大站` / `小站` / `终点站` |
| 15 | 外音开否 | `是` / `否` |

> 经纬度使用「度 + 十进制分」格式：`11930.6582` 表示 119°30.6582′，换算成十进制度是 119.51097°。应用在匹配 GPS 时会自动转换。

### audiolist.csv

前两列是 `播报类型` 和 `是否播报`（`是` / `否`），后面是该播报类型对应的音频槽位。支持的类型：`起点播报`、`终点播报`、`终点预报`、`进站播报`、`出站播报`、`进站外音`、`出站外音`。

### 与主流车载报站器数据格式兼容

本项目的线路数据包（`bus/` + `mp3/` + `system/`）沿用主流车载报站器通用格式，**可与「巴视通」「南大苏富特」「江宁公交信息科技」等厂家的车载报站器数据实现 100% 完美兼容**，双向导入导出都不需要手工转换：

- **目录结构一致**：`bus/[线路名]/[线路名]S.csv`、`[线路名]X.csv`、`mp3/`、`system/audiolist.csv`
- **线路 CSV 列序与含义一致**：固定 16 列（站台编号 → 外音开否），经纬度同为「度分」格式（DDMM.MMMM）
- **播报规则一致**：`audiolist.csv` 的播报类型与音频槽位对应（起点播报、终点播报、终点预报、进站播报、出站播报、进站外音、出站外音）
- **文件命名规则一致**：`S` = 上行、`X` = 下行，扩展名与字母大小写不敏感（`11s.csv`、`11S.CSV` 均可识别并统一规范为大写）
- **编码自动兼容**：UTF-8、UTF-8 BOM、UTF-16（LE/BE）、GB18030/GBK 均可直接导入，落库统一转成 UTF-8；导出的 CSV 为 UTF-8，可被厂家软件再次导入，中文不乱码
- **音频按名字匹配**：线路 CSV 里写文件名（不带 `.mp3`），找不到的单个文件静默跳过，不影响同组其他播报
- **导出可直接交付**：「一键导出所有数据（ZIP）」按 `bus/`、`mp3/`、`system/` 原始结构打包，可直接交给厂家工具或复制到另一台车机

> 换句话说：把厂家报站器导出的数据包直接「一键导入」到本 App，或把本 App 导出的 ZIP 交给厂家工具，均无需重排列、转编码或改名。若某厂家使用了非标准扩展列或特殊命名，反馈数据包即可按同一格式适配。

## 首次启动（不含内置数据）

本仓库和安装包**不包含任何线路数据和音频文件**：开发测试用的线路与 mp3 已全部移除，避免版权问题。首次启动时线路列表为空，可以：

1. 进入 **设置 → 数据导入和导出**，导入厂家的数据包（线路 ZIP、音频 ZIP、`audiolist.csv`，或整合 ZIP 一键导入）；或
2. 用 **设置 → 新增线路** 在内置编辑器里创建线路，再把 mp3 放进应用的 `mp3/` 目录。

缺少 `system/audiolist.csv` 时会自动使用内置的默认播报规则，所以只导入线路 CSV 和音频也能正常工作。

如果要在本机编译时带上自己的测试数据，放到 `app/src/main/assets/bus`、`app/src/main/assets/mp3`、`app/src/main/assets/system` 即可——这三个路径已写入 `.gitignore`，不会被提交到仓库。

## 构建与运行

需要 JDK 17、Android SDK 34，可使用 Android Studio 或命令行。

```bash
# 指定 SDK 位置（Windows 示例）
echo "sdk.dir=C:/Users/<你的用户名>/android-sdk" > local.properties

# 构建 Debug APK
./gradlew assembleDebug

# 产物
app/build/outputs/apk/debug/app-debug.apk
```

首次启动需要授予定位权限；没有定位权限时自动报站不可用，手动报站仍可正常使用。

## 说明与已知行为

- **响度均衡默认关闭**。开启后每个文件首次播放前会先分析（最多取样 30 秒），因此第一次可能略有延迟，之后使用缓存。
- **声道分离在 PCM 层完成**，所以单声道文件也能只从指定一侧出声；双声道文件会把对应一侧的内容保留在选定声道。
- **双击覆写站点位置**修改的是应用内部的线路 CSV 副本；重新导入线路包会覆盖这些手动修正。
- 切换线路、方向或导入数据后，自动播报状态会重置，之前已播过的站点可能会按新位置重新触发。
- 导出的 ZIP 保持 `bus/`、`mp3/`、`system/` 目录结构，可直接用「一键导入」还原。
- 导入时会自动检测编码并统一转换为 UTF-8，Windows/GBK 编码的 CSV 也能正常处理。
